# Sistema-de-Gerenciamento-de-Clientes-SmartData-

Projeto: Sistema de Gerenciamento de Clientes (SmartData)

Desenvolvido como parte de um teste técnico, este sistema utiliza a arquitetura MVC (Model-View-Controller) para garantir a organização e escalabilidade do código. O projeto contempla um fluxo completo de CRUD (Criação, Leitura, Atualização e Exclusão) de clientes, com controle de autenticação de usuários e validações de segurança tanto no front-end quanto no back-end.

Tecnologias utilizadas:

Linguagem: PHP.

Banco de Dados: MySQL.

Arquitetura: MVC (Model-View-Controller).

Interface: HTML5, CSS3 e SweetAlert2 para notificações dinâmicas.

O login padrão é: admin/123
